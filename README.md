# Fox-and-Crow

Fox-and-Crow is an in-progress project for testing generative LLM agents as a storyteller. `storyteller/` is a small engine for playable stories: the player is given an opening passage and a character, they write one line or one action at a time, and two agents answer — a **judge** that decides what that line changes in the world, and a **writer** that turns that decision into the next passage. The two run as a LangGraph state machine, one turn at a time. A story is supplied as a case under `cases/`, and a case is only data: a world written in each language, an opening, and the character the player plays. Two cases exist today, `fox-and-crow` (Aesop's fable, informed by Marie-Laure Ryan's work on interactive narrative and possible worlds) and `cinderella` (the Perrault tale). Neither carries a script, a clock, or a scoring system. Every story in the project is a loop, and a loop ends only when it is broken: playing the original tale to its expected end returns the first morning, and whether a turn is a repeat or a break is the agent's judgement, not the player's. Both cases are test inputs, and the repository remains under active development.
