# Fox-and-Crow

Fox-and-Crow is an in-progress project for testing generative LLM agents as a storyteller. `storyteller/` is a small engine for playable stories, built from three agents in a fixed order. The **understander** comes first: it reads the original tale and makes semantic sense of it — who these people are, what each of them wants, where they are, which rules hold there, and what the story's loop is — and abstracts that reading into a canon, which is the ground everything afterwards is judged against. Then the player is given an opening passage and a character, and writes one line or one action at a time; the **judge** decides, against that canon, what the line changes in the world; and the **writer** turns the judgement into the next passage. All three run as LangGraph state machines. A story is supplied as a case under `cases/`, and a case is only data: the original tale, in each language, with the derived understanding cached beside it. Two cases exist today, `fox-and-crow` (Aesop's fable, informed by Marie-Laure Ryan's work on interactive narrative and possible worlds) and `cinderella` (the Perrault tale). Neither carries a script, a clock, or a scoring system. Every story in the project is a loop, and a loop ends only when it is broken: playing the original tale to its expected end returns the first morning, and whether a turn is a repeat or a break is the agents' judgement, not the player's. Both cases are test inputs, and the repository remains under active development.
