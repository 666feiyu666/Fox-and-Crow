# Fox-and-Crow

Fox-and-Crow is an in-progress project for testing a generative LLM agent as a storyteller. `storyteller/` is a small engine for playable stories: the player is given an opening passage and a character, they write one line or one action at a time, and the agent — holding an omniscient view of that story's world — decides what each line changes and continues the story. A story is supplied as a case under `cases/`, and a case is only data: a world written in each language, an opening, and the character the player plays. Two cases exist today, `fox-and-crow` (Aesop's fable, informed by Marie-Laure Ryan's work on interactive narrative and possible worlds) and `cinderella` (the Perrault tale). Neither carries a script, a clock, or a scoring system; both are test inputs, and the repository remains under active development.
