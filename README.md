# Fox-and-Crow

Fox-and-Crow is an in-progress project for testing a generative LLM agent as a storyteller. `storyteller/` is a reusable engine in which the agent holds an omniscient view of a story world, judges what each thing the player says or does changes, and narrates the consequence — closer to a tabletop dungeon master than to a branching script. A story is supplied as a case under `cases/`: world canon, an opening scene, and the mechanics the runtime keeps. Two cases exist today, `fox-and-crow` (a repeating day, informed by Marie-Laure Ryan's work on interactive narrative and possible worlds) and `cinderella` (a single night with no reset); both are test inputs, and the repository remains under active development.
