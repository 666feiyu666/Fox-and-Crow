# Fox-and-Crow

Fox-and-Crow is an in-progress interactive-narrative project, informed by Marie-Laure Ryan's work on interactive narrative and possible worlds, that turns Aesop's fable into a playable story: the player is the fox, and an omniscient Storyteller agent, closer to a tabletop dungeon master than to a branching script, judges what each thing the player says or does changes in the world and narrates the consequence. Current work is a deliberate rewrite around that Storyteller role, so the runnable app under `app/fox-and-crow-mvp/` and the case material under `cases/fox-and-crow/` are both still under active development and may change before the next milestone.
