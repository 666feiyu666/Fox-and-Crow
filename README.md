# The Fox and the Crow: A Day in Loop

Fox-and-Crow is an in-progress interactive narrative project inspired primarily by Marie-Laure Ryan’s work on interactive narrative and possible worlds. It adapts Aesop’s fable into a looping story in which the player, as the fox, must move beyond the original trick to uncover the crow’s hidden situation and create a different ending. Current work uses this task to refine a theory-guided Narrative AI approach and prepare the existing runnable MVP for a deliberate rewrite; the repository remains under active development, and its structure and implementation may change before the next milestone.
